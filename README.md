# Turon B2C — дашборд отдела продаж

Панель управления продажами туристического агентства с разграничением по
ролям: руководитель отдела видит картину по всей команде, менеджер — только
свои показатели.

Источники данных текущей статической версии — отчёт о продажах и недельные
выгрузки кампаний Meta Ads в формате Excel.

## Статус

Статическая страница содержит 139 сделок за май–август 2026 года и раздел
«Маркетинг» с недельными выгрузками Meta Ads за 20–26 июля и 17–23 августа.
Схема данных и ТЗ описывают возможное дальнейшее развитие приложения.

## Обновление статической страницы

Из корня репозитория в PowerShell выполните команды ниже. На этом Windows
компьютере указан bundled Python с установленным `openpyxl`; в другой среде
подойдёт Python 3 с установленным `openpyxl`. Перед сборкой передайте парсеру
**все** недельные выгрузки Meta Ads за нужные периоды. Месяц считается полным
только тогда, когда выгрузки покрывают каждый его день; одна июльская и одна
августовская неделя дают неполные месяцы.

```powershell
$python = 'C:\Users\User\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe'
New-Item -ItemType Directory -Path data -Force | Out-Null
& $python scripts/parse_report.py 'C:\Users\User\Downloads\Отчеты (3).xlsx' -o data/deals.json
& $python scripts/parse_marketing.py `
  'C:\Users\User\Downloads\Telegram Desktop\Turon_Tour_Рекламный_аккаунт_Кампании_20_июл_2026_г_26_июл_2026.xlsx' `
  'C:\Users\User\Downloads\Telegram Desktop\Turon_Tour_Рекламный_аккаунт_Кампании_17_авг_2026_г_23_авг_2026.xlsx' `
  -o data/marketing.json
& $python scripts/build_dashboard.py --sales data/deals.json --marketing data/marketing.json --out index.html
```

Итоговый `index.html` — один самодостаточный HTML-файл: данные вшиты внутрь,
сервер не нужен. При добавлении новых недель перечислите их файлы в команде
`parse_marketing.py` и снова выполните сборку. Если даты новой выгрузки
пересекаются с уже принятой, парсер сохранит первую, пропустит пересекающуюся
и добавит замечание к данным; соседние периоды без общих дат принимаются.

Расход в разделе «Маркетинг» взят из Meta Ads за выбранную неделю или
неполный месяц. «Рекламные удержания по отчёту продаж» — отдельный финансовый
показатель из книги продаж. Эти суммы не сверяются и не распределяются между
менеджерами; рекламные кампании не связываются со сделками.

## Как развернуть базу

```bash
psql "$DATABASE_URL" -f db/schema.sql
psql "$DATABASE_URL" -f db/rls.sql
```

Схема рассчитана на PostgreSQL 15+ и предполагает Supabase Auth
(таблица `auth.users`).

## Персональные данные

`data/*.json` содержит исходные разобранные данные и исключён из репозитория
через `.gitignore`. Собранный `index.html` содержит встроенные сведения о
сделках, включая ФИО клиентов, и отслеживается в репозитории. Перед публичным
размещением проверьте допустимость раскрытия этих данных. Переключатель
«Скрыть имена клиентов» скрывает их только на экране и не удаляет из HTML.
