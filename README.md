# Turon B2C — дашборд отдела продаж

Панель управления продажами туристического агентства с разграничением по
ролям: руководитель отдела видит картину по всей команде, менеджер — только
свои показатели.

Источник данных на первом этапе — Google-таблица с заявками.

## Документы

| Файл | Что внутри |
|---|---|
| [`docs/tz.md`](docs/tz.md) | Техническое задание: роли, метрики и формулы, состав экранов, стек, дизайн-система, этапы |
| [`docs/google-sheets-format.md`](docs/google-sheets-format.md) | Формат листа-источника и правила его ведения — для тех, кто ведёт таблицу |
| [`db/schema.sql`](db/schema.sql) | Схема БД: таблицы, индексы, аналитические вьюхи |
| [`db/rls.sql`](db/rls.sql) | Политики доступа (RLS): разграничение РОП / менеджер |

## Статус

Этап проектирования. Код приложения ещё не написан — сначала утверждается
ТЗ и схема данных.

## Как развернуть базу

```bash
psql "$DATABASE_URL" -f db/schema.sql
psql "$DATABASE_URL" -f db/rls.sql
```

Схема рассчитана на PostgreSQL 15+ и предполагает Supabase Auth
(таблица `auth.users`).
